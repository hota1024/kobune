# 日本語

`aa141bf` 時点の `docs/ja/` から起こした規則です。根拠の実測値を併記して
あります。「例外 0」と書いてある規則に例外が現れた場合、それは規則が緩んだ
のではなく、その文が間違っています。

この文書自体も、ここに書かれた規則で書いてあります。

## 何より先に

**英語を訳すのではなく、日本語で書きます。** 英語版と日本語版は同じことを
言いますが、同じ形をしている必要はありません。英語の一文が日本語では二文に
なることも、順序が入れ替わることもあります。

翻訳調は次の形で現れます。見つけたら組み替えてください。

- 英語の関係詞節を、そのまま読点でつないだ長い一文
- ダッシュの数が英語版と一致している段落
- 「〜することによって」「〜という事実」「〜のうちの 1 つ」
- 主語を補いすぎた文。日本語では省くほうが自然な場面が多くあります

## 文体

**ですます調です。** 608 文すべてがそうで、例外はありません。「である」
「だ」で終わる文は混ぜません。

**現在形で書きます。** 「1 行だけを出力します」であって、「出力するはずです」
ではありません。

**推測を書きません。** 動作を確かめていないなら、確かめるか、書かずに残す
かのどちらかです。

## 表記

**和欧間に半角スペースを入れます。** 違反 0 件です。日本語と半角英数字が
隣り合う箇所すべてが対象で、コードスパンやリンクも同じ扱いです。

> `minato url` は 1 行だけを出力するため、パイプにそのまま使えます。

ただし、次の場合は入れません。

- 句読点・全角括弧に接するとき（`です。API` であって `です。 API` ではない）
- 行頭・行末
- コードブロックの中

**数詞と助数詞の間にも半角スペースを入れます。** 18 ページが `3 つ`、
`reference/cli.md` だけが `3つ` です。多数派に揃えます。

**括弧は全角の `（）` です。** 全角 22 件、半角 0 件。半角の `()` は
コードの中だけで使います。

**句読点は `、` と `。` です。** `，` `．` は使いません。

**感嘆符と疑問符は使いません。** 見出しの `Minato とは` のように、
言い切るか体言止めにします。

**全角の英数字とスペースは使いません。**

## ダッシュ

**単独の `—` は日本語本文では使いません。** 英語版は 180 箇所で ` — ` を
使いますが、日本語はこれを引き継ぎません。現状は `——` が 28 箇所、`—` が
29 箇所で割れており、ここで一本化します。

英語のダッシュに出会ったら、次のいずれかへ組み替えます。

| 英語 | 日本語 |
| --- | --- |
| 補足を付け足す | 文を `。` で切って二文にする |
| 言い換える | 「つまり」「すなわち」で受ける |
| 定義や具体例を並べる | `：` で受けるか、`（）` に入れる |
| 対比する | 「一方」「これに対して」で受ける |

**どうしても挿入句が必要な場合だけ `——`（2 倍ダッシュ）を使います。**
1 ページに 1 つあるかどうか、という頻度です。

## 語彙

**長音符号は付けません。** `サーバ` 10 件に対し `サーバー` 1 件です。
`ブラウザ` `ディレクトリ` `プロキシ` も同様に付けません。

用語の対応は `glossary.md` にまとめてあります。`worktree` `workspace` の
ようにラテン文字のまま残すものと、`サービス` `コンテナ` のようにカタカナに
するものの境界は、そちらが決めます。

**冗長な言い回しを避けます。**

| 使わない | 使う |
| --- | --- |
| することができます | できます |
| 〜を行います | その動詞そのもの（「設定を行います」→「設定します」） |
| 〜となります | 〜です／〜になります |
| 〜する必要があります | 〜します（義務でないなら書かない） |
| 基本的に、原則として | 条件を具体的に書く |
| 〜のような形になります | 断定する |

**`〜してください` は、読者に実行を求めるときだけです。** 現状 55 件あり、
説明文に紛れているものがあります。動作の説明なら「〜します」、注意の喚起
なら「〜に注意します」で足ります。

**「簡単に」「単純に」「もちろん」は書きません。** 簡単なら、その文は
不要です。

## 見出し

**体言止めか、動詞で終わる短い句にします。** `最初の環境`『設定』
`ランタイムを切り替える` のいずれの形もありますが、1 ページの中では
揃えます。

**英語版と同じ数・同じ階層です。** 文言は一致していなくてかまいません。

**`config.ts` の `PAGES` に書かれた題と、ページの `H1` を一致させます。**
現在 `docs/ja/guide/getting-started.md` だけがずれています（`PAGES` は
`最初の環境を作る`、`H1` は `最初の環境`）。

## 組版

**表示幅 80 桁で折り返します。** 全角文字は 2 桁として数えます。
frontmatter・表・コードブロック・分割できない URL は対象外です。

**行末で改行を入れるとき、単語やコードスパンの途中では折りません。**
`docs/ja/` は助詞の直後で折っている箇所が多く、読点の直後も同様に自然です。

**ファイルの末尾は改行 1 つで終わり、行末に空白を残しません。**

## 訳さないもの

**コンソール出力は訳しません。** プログラムが実際に出力した文字列です。

**コードブロック内のコメントは訳します。** 書き手の言葉だからです。

```console
$ minato logs web -f          # このブランチのログを追跡する
```

**設定キー・フラグ・環境変数・終了コードの名前は訳しません。**
説明だけを日本語にします。
